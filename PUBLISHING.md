# Publishing Tekzite DNS

Publish this code as an **experimental release candidate** (`v0.1.0-rc5`), not as a stable production release.

1. Verify the Python CI workflow on GitHub Actions before creating a pre-release tag `v0.1.0-rc5`.
2. Enable GitHub private vulnerability reporting (Settings > Code security and analysis / Security).
3. Do not claim the 12–24 hour soak test or external review has passed. Do not deploy over the active DNS service yet.
